Developer ↔ Critic (ReAct, ≤ 5 iters)

Success = a sandboxed Flag Checker

a deterministic run decides success — not the model's self-report

NT521.R11.ANTN · Reproducing CVE-GENIE

The pipeline decomposes reproduction into four dependent modules. Each (except the deterministic Processor core and Flag Checker) runs a developer+critic ReAct loop to self-correct, up to five iterations. Crucially, success is judged by a sandboxed Flag Checker printing a secret flag — not by the model claiming success.
