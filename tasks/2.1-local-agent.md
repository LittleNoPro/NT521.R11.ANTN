# 2.1-local-agent: Endpoint model local + agent loop tối giản (điểm cộng)
Goal: Dựng một endpoint OpenAI-compatible chạy model local nhỏ, và một bản hiện thực TỐI GIẢN của 1 vòng developer↔critic kiểu CVE-GENIE (ưu tiên Exploiter hoặc Builder) trỏ vào endpoint đó.
Context: PLAN.md §2 mức D, §6. GPU 6GB → model ~3–4B quantized (llama.cpp GGUF qua `llama-server`, hoặc vLLM model nhỏ). Paper: open-model yếu ở agentic tool-calling — ta sẽ đo lại.
Owned files: local_agent/, docs/local-model-setup.md
Do not touch: cve-genie/ bản gốc (nếu cần dựa theo thì copy prompt vào local_agent/), file task khác.

Steps:
1. Chọn & chạy 1 model local nhỏ hỗ trợ tool/function-calling (vd Qwen2.5-3B-Instruct GGUF). Phơi endpoint OpenAI-compatible (/v1/chat/completions). Ghi RAM/VRAM thực tế.
2. Viết local_agent/agent.py: 1 vòng ReAct tối giản — developer agent có vài tool read-only (exec trong container, read_file, write_file, run) + critic agent review log. Giữ nhỏ, có giới hạn số bước.
3. Cắm knowledge base tối giản cho CVE-2024-4340 (lấy từ T1.2) làm input.
4. Mục tiêu khiêm tốn & trung thực: xem model local có tự sinh được PoC chạy được cho CVE dễ không; nếu không, ghi lại chính xác nó hỏng ở đâu (không gọi tool / sai cú pháp / bịa).
5. Tài liệu hoá kiến trúc rút gọn so với CVE-GENIE (bỏ gì, giữ gì) và lý do.

Done when (phải tự kiểm chứng):
- `./local_agent` chạy được: endpoint trả lời, agent.py thực hiện ≥1 vòng developer→tool→critic và lưu transcript.
- docs/local-model-setup.md: model nào, cách chạy, tài nguyên, kiến trúc rút gọn, giới hạn.
Report back: model + tài nguyên, agent có chạy loop không, quan sát ban đầu về chất lượng.
