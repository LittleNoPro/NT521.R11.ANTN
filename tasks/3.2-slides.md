# 3.2-slides: Slide thuyết trình
Goal: Bộ slide trình bày (và kỹ năng thuyết trình) phủ: ngữ cảnh/vấn đề, phương pháp, demo, kết quả, ưu/nhược.
Context: PLAN.md. Nguồn: report/ (T3.1) + docs/. Định dạng: ưu tiên Marp/reveal.js markdown (xuất HTML/PDF) để chạy offline; hoặc outline chi tiết.
Owned files: slides/
Do not touch: file task khác.

Steps:
1. Outline ~15–18 slide: (1) tiêu đề, (2) bài toán & động lực, (3) tại sao khó/các cách cũ, (4) EAGER, (5) tổng quan kiến trúc, (6–9) 4 module, (10) chọn LLM & vì sao open-model yếu, (11) thiết lập đánh giá + kết quả paper, (12–14) phần tái hiện của nhóm (A/B/C), (15–16) điểm cộng: model local + CVE mới, (17) ưu/nhược, (18) kết luận + demo.
2. Mỗi slide: tiêu đề + 3–5 bullet ngắn + ghi chú nói (speaker notes).
3. Nhúng số liệu & 1–2 sơ đồ (luồng pipeline, ví dụ CVE-2024-4340).
4. Thêm 1 slide "demo" chỉ rõ sẽ chạy gì (gói từ T3.3).

Done when (phải tự kiểm chứng):
- slides/ có file nguồn (vd slides.md Marp) + bản xuất HTML hoặc PDF.
- Có speaker notes cho mỗi slide chính.
Report back: đường dẫn slide, bản xuất đã tạo chưa.
