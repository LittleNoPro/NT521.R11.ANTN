# 1.1-replay-artifacts: Tái hiện kết quả từ artifacts đã công bố (Docker, không API)
Goal: Chứng minh exploit+verifier CVE-GENIE công bố thực sự chạy được: dựng lại môi trường, chạy exploit, verifier in ra đúng flag — cho 3–5 CVE.
Context: PLAN.md §2 mức A, §4. Dùng danh sách CVE từ docs/setup.md (T0.1). Bắt đầu với CVE-2024-4340.
Owned files: repro/artifacts/, docs/repro-artifacts.md
Do not touch: cve-genie/ (chỉ đọc), file task khác.

Steps:
1. Với mỗi CVE đã chọn: đọc artifact trong cve-genie/results/<CVE> (poc/exploit script, verifier script, metadata, hướng dẫn môi trường).
2. Viết 1 Dockerfile (hoặc docker run) dựng lại đúng phiên bản phần mềm bị lỗi (vd sqlparse==0.4.4 trên python). KHÔNG chạy trên host.
3. Trong container: cài version lỗi, chạy exploit script đã công bố, rồi chạy verifier script; ghi lại stdout/flag.
4. So sánh flag/thành công với metadata của tác giả. Lập bảng: CVE | dựng env OK? | exploit chạy? | verifier ra đúng flag? | khớp paper?
5. Lưu mỗi CVE 1 thư mục repro/artifacts/<CVE>/ gồm: Dockerfile, lệnh chạy, log output.

Done when (phải tự kiểm chứng):
- ≥3 CVE chạy được end-to-end trong Docker, verifier in đúng flag mong đợi (chụp log).
- CVE-2024-4340 nằm trong số đó.
- docs/repro-artifacts.md có bảng kết quả + lệnh tái lập + ghi chú CVE nào fail và vì sao.
Report back: bảng kết quả, log chính, CVE fail + nguyên nhân.
