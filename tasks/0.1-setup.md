# 0.1-setup: Clone repo, dữ liệu, env, kiểm kê artifacts
Goal: Có bản clone CVE-GENIE chạy được + dữ liệu CVE + danh sách artifacts đã công bố để tái hiện.
Context: PLAN.md §0, §1, §4. Repo: https://github.com/BUseclab/cve-genie (Apache-2.0).
Owned files: cve-genie/ (clone), env/ (venv), docs/setup.md
Do not touch: mọi thứ trong repro/, local_agent/, report/, slides/, demo/

Steps:
1. `git clone --depth 1 https://github.com/BUseclab/cve-genie.git` vào thư mục dự án.
2. Tạo venv: `python3 -m venv env && ./env/bin/pip install -r cve-genie/src/data/requirements.txt`; `./env/bin/playwright install` (nếu lỗi do thiếu lib hệ thống thì ghi lại, không bắt buộc cho phần offline).
3. Dữ liệu CVE: KHÔNG clone full cvelistV5 (quá lớn). Thay vào đó tải trực tiếp JSON các CVE cần qua GitHub raw, HOẶC shallow+sparse clone chỉ nhánh năm 2024. Ghi cách đã dùng vào docs/setup.md.
4. Tạo cve-genie/src/.env với GITHUB_TOKEN (hỏi user token, hoặc hướng dẫn tạo PAT read-only). KHÔNG commit .env.
5. Kiểm kê thư mục `cve-genie/results/`: liệt kê các CVE đã có artifact đầy đủ (có exploit script + verifier script + metadata). Chọn ra 5 ứng viên CVE "dễ, single-process" cho Phase 1 (gồm CVE-2024-4340). Ghi bảng vào docs/setup.md.
6. Đọc cve-genie/README.md, PROCESSING.md, RESULTS.md; tóm tắt cấu trúc repo và cách 1 artifact run được tổ chức (thư mục nào chứa exploit/verifier/poc).

Done when (phải tự kiểm chứng trước khi báo):
- `ls cve-genie/src/main.py` tồn tại; `./env/bin/python -c "import playwright"` không lỗi (hoặc đã ghi rõ lib thiếu).
- docs/setup.md có: cách lấy dữ liệu CVE, bảng ≥5 CVE ứng viên (CVE ID, project, ngôn ngữ, loại lỗi, đường dẫn artifact, single-process hay không), và sơ đồ 1 artifact run.
- Tải thử thành công JSON của CVE-2024-4340 (chứng minh đường dữ liệu hoạt động).
Report back: tóm tắt thay đổi, lệnh đã chạy + kết quả, 5 CVE đã chọn, vấn đề còn mở.
