Goal: Dùng agent local (T2.1) chạy trên CVE-2024-4340 VÀ ≥1 CVE MỚI (ngoài tập 60/841 của paper); đo kết quả, so với phát hiện open-model của paper → đây là "kịch bản/dữ liệu mới" + biện luận.
Context: PLAN.md §2 mức D. Phụ thuộc T2.1 (agent) + T1.2 (processor cho CVE mới). Chọn CVE mới: dễ, single-process, có PoC công khai, Processor lấy được dữ liệu.
Owned files: experiments/, docs/bonus-analysis.md

Steps:
1. Chọn 1–2 CVE MỚI (nêu rõ vì sao không trùng tập paper; kiểm chứng ngày công bố/loại). Lấy dữ liệu bằng Processor (T1.2).
2. Chạy agent local trên: CVE-2024-4340 (đã biết dễ) + CVE mới. Mỗi lần ghi: số vòng, tool-call hợp lệ/không, có ra PoC chạy được không, có qua verifier không.
3. Lập bảng kết quả + chi phí thời gian (và chi phí $ = 0 vì local). Đối chiếu định tính với bảng open-model của paper (Qwen mô tả mà không gọi tool, v.v.) — khớp hay khác?

- Khẳng định trung thực: nếu model local fail, nói rõ fail thế nào (đó vẫn là kết quả hợp lệ, củng cố nhận định của paper).
