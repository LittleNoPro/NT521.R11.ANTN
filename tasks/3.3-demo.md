# 3.3-demo: Gói demo chạy được
Goal: Một demo gọn, bấm-là-chạy để trình bày trực tiếp, không cần API trả phí.
Context: PLAN.md §2. Nguồn: repro/ (T1.1, T1.3), local_agent/ (T2.1). Khán giả: hội đồng chấm.
Owned files: demo/
Do not touch: file task khác (chỉ gọi lại, không sửa).

Steps:
1. Kịch bản demo (demo/README.md) theo thứ tự: (a) Processor trích CVE-2024-4340 live; (b) dựng env + chạy exploit+verifier đã công bố trong Docker → ra flag; (c) exploit/verifier tự viết → ra flag; (d) (tùy chọn) agent local chạy 1 vòng.
2. Script bọc demo/run_demo.sh gọi các bước, in rõ ràng từng giai đoạn, dừng chờ enter giữa các bước để thuyết trình.
3. Đảm bảo chạy được từ máy sạch: ghi điều kiện tiên quyết (Docker, env, token) và thời lượng ước tính mỗi bước.
4. Có phương án offline hoàn toàn (nếu mất mạng): dùng JSON/artifact đã lưu sẵn.

Done when (phải tự kiểm chứng):
- `bash demo/run_demo.sh` chạy trọn các bước (a)(b)(c) trên máy này, in flag thành công.
- demo/README.md có điều kiện tiên quyết + thời lượng + phương án offline.
Report back: các bước đã chạy được, thời lượng, điểm nghẽn khi demo.
