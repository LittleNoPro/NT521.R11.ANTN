# 3.1-report: Báo cáo chi tiết
Goal: Báo cáo đồ án hoàn chỉnh (markdown, có thể xuất PDF) gộp toàn bộ hiểu biết + kết quả thực nghiệm + biện luận.
Context: PLAN.md toàn bộ. Nguồn: docs/method-notes.md, docs/repro-*.md, docs/bonus-analysis.md.
Owned files: report/
Do not touch: docs/ (chỉ đọc), file task khác.

Steps (cấu trúc báo cáo):
1. Giới thiệu: ngữ cảnh, vai trò, vấn đề bài toán (vì sao dataset CVE tái hiện được là quan trọng & khó).
2. Phương pháp CVE-GENIE: EAGER, 4 module, multi-agent, chọn LLM/prompt (từ T0.2).
3. Tái hiện thí nghiệm: mức A (replay artifacts), mức B (Processor live), mức C (thủ công) — bảng + log.
4. Điểm cộng: thí nghiệm model local trên CVE cũ + mới, cải tiến, kết quả (từ T2.2).
5. Biện luận ưu/nhược điểm (có dẫn chứng thực nghiệm).
6. Kết luận + hạn chế của bản tái hiện (trung thực: không có API nên lõi dựa trên artifacts).
7. Phụ lục: lệnh tái lập, cấu hình môi trường, tài liệu tham khảo.

Done when (phải tự kiểm chứng):
- report/report.md đủ 7 mục, mọi số liệu paper có trích dẫn, mọi khẳng định thực nghiệm trỏ tới log/thư mục cụ thể.
- Có hướng dẫn tái lập để người chấm chạy lại được phần offline.
- (Nếu có pandoc) xuất thử report/report.pdf.
Report back: đường dẫn báo cáo, mục nào còn chờ dữ liệu từ task khác.
